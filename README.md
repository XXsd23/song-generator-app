# SongForge Studio

A lightweight web app for turning lyrics, a chosen music genre, and a voiceover style into a structured song concept.

## Features
- Lyrics editor
- Genre selector with BPM and tonal mood presets
- Voiceover style picker
- Auto-generated song structure with verse / chorus / bridge sections
- Browser-based preview audio and voiceover support
- Responsive UI for desktop and mobile

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL in your browser.

## Build

```bash
npm run build
```
